# Links & Rechts Trainer

Übungs-App, um links und rechts sicher zu unterscheiden.

## Sofort benutzen
`index.html` doppelklicken, die App öffnet sich im Browser.

## Mit Claude Code weiterentwickeln
1. Claude Code installieren (Anleitung: https://docs.claude.com, Bereich Claude Code).
2. Eingabeaufforderung oder Terminal in diesem Ordner öffnen.
3. `claude` eingeben. Claude Code liest automatisch die `CLAUDE.md` und kennt damit das Projekt.
4. Wünsche einfach auf Deutsch schreiben, z. B.:
   - „Füge eine Übung hinzu, bei der eine Stimme sagt: Heb die linke Hand.“
   - „Mach die Weg-Übung auf Stufe 3 mit zwei Abbiegungen.“
   - „Baue einen Elternbereich mit Statistik der letzten 7 Tage.“

## Aufs Handy bringen
Den Ordner kostenlos hosten (z. B. GitHub Pages oder Netlify), Link auf dem Handy öffnen
und „Zum Startbildschirm hinzufügen“ wählen. Claude Code kann das Hosten für dich einrichten.
